# AKoopasRevenge2Archipelago
Archipelago implementation for "A Koopa's Revenge 2"

Setup Guide:
Install the patch file and apworld
Patch your copy of the game using Delta Patcher
Run the dedicated client and boot up the game in ruffle

Commands:
/game: checks if the game is connected or not.
/warp: lets you warp to any available level in the game, run the command to see the list.
/powerup: lets you select any unlocked powerup at any time from the overworldm run the command to see the list.
/disablecheats: disables any unwanted cheats (Use if you find Space Jump and/or Screw attack before the multiworld item, as they are activated instantly)
